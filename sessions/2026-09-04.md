# Session: 2026-09-04

## Goal

Create and ship Codex Usage Status: a dockless macOS HUD that MousePlus can summon to show Codex rate-limit usage.

## Progress

- Created a SwiftUI/AppKit macOS agent app with no Dock icon, a Carbon global hotkey (`⌃⌥⌘X`), cursor-adjacent `NSPanel`, click-away dismissal, and a right-click Quit/Restart menu.
- Added live Codex usage retrieval from the local Codex session, explicit unavailable-window UI, and exact reset countdowns.
- Added the Icon Composer export as the application icon and README image.
- Initialized and published the MIT-licensed public repository, CI workflow, source release, and signed/notarized v0.1.0 DMG download.
- Verified unit tests throughout; the final DMG passed Apple notarization and Gatekeeper assessment.

## Decisions

- Use a dockless, non-activating HUD rather than a menu-bar utility; MousePlus supplies the trigger.
- Show unavailable quota windows explicitly rather than fabricating data when Codex returns only one rate-limit window.
- Publish a Developer ID-signed, notarized DMG rather than an unsigned archive.

## Next
